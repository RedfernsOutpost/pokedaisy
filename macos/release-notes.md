**Daisy Launcher** is an unofficial Mac version of [PokeDaisy](https://pokedaisy.com) by lidor30, with a game launcher made for the Mac. It isn't made or supported by PokeDaisy's developer; PokeDaisy has no official Mac version. Apple Silicon Macs (M1 or newer), macOS 13 or later.

**No games are included.** Use your own game files.

## New in Mac @N@

- Based on PokeDaisy @TAG@ (see [its changes](https://gitlab.com/pokedaisy/pokedaisy/-/tags/@TAG@)).

## Install or update

- **Already have Daisy Launcher?** Settings → VERSION → UPDATE does it for you.
- **New, or coming from PokeDaisy for Mac 1–3:** download **DaisyLauncher-Mac.zip** below, double-click it, and drag **Daisy Launcher** into Applications (you can delete the old PokeDaisy app). Your games, saves and settings carry over.

Signed and notarized by Apple, so it opens like any other app.

## Source

GPL-3.0, like PokeDaisy. This build is the [`mac-launcher`](https://github.com/RedfernsOutpost/pokedaisy/tree/mac-launcher) branch at commit @COMMIT@; PokeDaisy's own source is at https://gitlab.com/pokedaisy/pokedaisy. Build it yourself with `zsh macos/build.sh` (see `macos/README.md`). The licenses for the included parts (mGBA, DSperate, SDL and others) are in the app's Resources folder.
